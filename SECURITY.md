# Security policy

Only the latest ReelSave release receives security fixes.

For a suspected security vulnerability, use GitHub's private vulnerability reporting form in the repository's **Security** tab. For ordinary download failures, use ReelSave's **Report a problem** button.

Do not include cookies, account credentials, video links, local file paths, tokens, or raw application logs in a public issue. ReelSave's built-in report preview deliberately excludes those fields.
